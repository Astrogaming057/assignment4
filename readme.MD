# Assignment 4 - Merge Conflict

This project is a simple HTML file created for Assignment 4 to practice handling merge conflicts. 

## Installation

No installation is required. Simply download or clone this repository to your local machine.

## Usage

1. Open the `TEST.HTML` file in your web browser.
2. View the contents, which include a greeting and the name of a favorite book.
